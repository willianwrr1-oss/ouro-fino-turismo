### 📚 Períodos Históricos (4)

1. **Descoberta do Ouro** (séc. XVII)
   - Bandeirantes paulistas exploram Minas Gerais
   - Descoberta entre 1693-1695
   - Interesse da Coroa Portuguesa

2. **Fundação do Arraial** (1708)
   - Fundado por Francisco Martins Lustosa
   - Disputa entre São Paulo e Minas Gerais
   - Jurisdição atribuída a Minas por Dom João V

3. **Ciclo do Ouro** (séc. XVIII)
   - Auge econômico de Ouro Fino
   - Impostos: Quinto (20%) e Derrama
   - Mineração com técnicas de bateia e canaletas
   - Gradual esgotamento dos depósitos

4. **Transformação Moderna** (séc. XIX-XX)
   - Evolução para atividades diversificadas
   - Ascensão da indústria têxtil
   - Música "Menino da Porteira" (1955)
   - Desenvolvimento como polo turístico

## 🚀 COMO USAR

### 1. Compilar Localmente

```bash
cd ouro-fino-turismo

# APK para teste
./gradlew assembleDebug

# APK para produção
./gradlew assembleRelease
```

**Resultado**: APKs em `app/build/outputs/apk/`

### 2. Instalar em Dispositivo

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 3. Publicar no GitHub

```bash
git init
git add .
git commit -m "Commit inicial: Ouro Fino Turismo v1.0"
git remote add origin https://github.com/SEU_USUARIO/ouro-fino-turismo.git
git branch -M main
git push -u origin main

# Criar primeira release
git tag -a v1.0.0 -m "Version 1.0.0"
git push origin v1.0.0
```
