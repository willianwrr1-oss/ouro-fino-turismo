🚀 RÁPIDO (3 PASSOS):
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Abrir no Android Studio
  → Clique em: File → Open → Selecione a pasta

PASSO 2: Compilar
  → Abra terminal na pasta do projeto
  → Execute: ./gradlew assembleDebug

PASSO 3: Instalar
  → Conecte celular via USB
  → Execute: adb install app/build/outputs/apk/debug/app-debug.apk
